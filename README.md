# WELLNEX AI – Intelligent Wellness Chatbot

An AI-powered wellness chatbot that delivers personalized health insights through smart, data-driven conversations.

## 📁 About

**WELLNEX AI** is designed to make health guidance more interactive, accessible, and personalized. By collecting essential user details such as **Gender, Age, Height, and Weight**, the app automatically calculates **BMI** and uses this data to provide accurate, contextual, and user-specific wellness responses.

By blending conversational AI with wellness logic, WELLNEX AI transforms generic health advice into meaningful, personalized guidance.
